一、Diffusers 是什麼

Diffusers 是 Python 函式庫，協助載入不同擴散模型並執行生成流程。它提供 pipeline，也允許進階使用者替換排程器或模型元件。

二、典型流程

選模型並閱讀模型卡；準備 Python 與運算設備；載入文字生圖 pipeline；提供提示詞與參數；檢查輸出並保存版本設定。

三、概念示意

文字提示詞 → 文字編碼 → 擴散模型逐步去噪 → VAE 解碼 → 輸出圖片。不同模型架構可能不同，這只是簡化示意。

四、容易忽略的事

VRAM 需求會隨模型與解析度改變；模型來源與授權要確認；範例程式可能隨函式庫版本更新。
