實作教學：把靜態網站發布到 GitHub Pages

更新日期：2026-11-13　閱讀時間：約 1–3 分鐘

摘要：GitHub Pages 可發布儲存庫中的靜態網站；發布前要確認首頁檔名、資源路徑與設定。

前言與學習目標

整理建立 Repository、設定 Pages 與測試網站的基本步驟。

  • 建立並整理網站儲存庫。
  • 設定 GitHub Pages 發布來源。
  • 測試網站連結與資源路徑。

步驟一：整理專案

建議至少包含 index.html、about.html、assets/css、assets/js 與 articles 資料夾。

步驟二：建立 Repository

在 GitHub 建立儲存庫，依需求選擇可見度，再上傳網站檔案或使用 Git push。確認 index.html 位於預期發布目錄。

步驟三：啟用 Pages

進入 Repository 的 Settings，找到 Pages，選擇發布來源，例如指定分支與資料夾，儲存後等待部署。

步驟四：測試網站

確認首頁、CSS、JavaScript、圖片、文章連結與手機版都正常。若樣式消失，檢查是否使用錯誤的絕對路徑。

重點整理

  • 建立並整理網站儲存庫。
  • 設定 GitHub Pages 發布來源。
  • 測試網站連結與資源路徑。
