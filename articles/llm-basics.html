大型語言模型（LLM）如何產生文字？

更新日期：2026-11-10　閱讀時間：約 1–3 分鐘

摘要：LLM 透過大量資料學習語言模式，依上下文預測 token；流暢回答不代表每個細節都正確。

前言與學習目標

以白話介紹 token、上下文與下一個 token 預測。

  • 理解 token 與下一個 token 預測。
  • 知道訓練與生成的差異。
  • 認識模型能力邊界。

一、從文字到 Token

模型通常不直接把整句文字當成單位，而會先切成 token。Token 可能是字、詞的一部分或符號，再轉成數值供模型運算。

二、模型如何生成

模型讀取上下文，計算下一個 token 的機率，再依解碼策略選出 token。新 token 加回上下文後，重複此過程直到停止。

三、為什麼會有幻覺

模型產生的是符合上下文的文字，不等於每句話都經外部資料庫驗證。缺乏資料或問題含糊時，可能生成看似合理但錯誤的細節。

四、使用建議

提供背景與來源；要求區分事實、推論與不確定處；重要資訊回到原始來源核對。
