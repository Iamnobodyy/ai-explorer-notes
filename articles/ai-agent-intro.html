AI Agent 是什麼？從回答問題到執行任務

更新日期：2026-11-10　閱讀時間：約 1–3 分鐘

摘要：AI Agent 通常是模型搭配工具、規則與工作環境，能規劃步驟、採取行動並觀察結果。

前言與學習目標

介紹 AI Agent 的模型、工具、上下文、規則與執行環境。

  • 理解 Agent 的基本組成。
  • 分辨單次回答與多步驟任務。
  • 認識權限與人工監督。

一、從聊天到行動

一般聊天多是提問與回答；Agent 型系統可能先規劃步驟、呼叫工具、觀察結果，再決定下一步。

二、常見組成

模型負責理解與決策；工具負責搜尋、讀寫檔案或執行程式；上下文提供資訊；規則與權限限制操作；執行環境提供工作空間。

三、範例：整理課堂資料

讀取指定講義；依格式整理重點；建立摘要與名詞表；檢查檔案是否存在；回報完成項目與待確認事項。

四、為何需要規則檔

AGENTS.md 或 CLAUDE.md 可記錄專案目的、資料夾結構、程式風格、禁止操作與完成標準，但仍需檢查 AI 是否遵守。
