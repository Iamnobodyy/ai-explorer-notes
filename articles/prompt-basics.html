Prompt 基礎：怎麼把問題問清楚

更新日期：2026-11-13　閱讀時間：約 5 分鐘

摘要：用「角色、任務、背景、格式、限制」五個要素，寫出更穩定、可重複使用的提示詞。

前言與學習目標

Prompt（提示詞）是你交給大型語言模型（LLM, Large Language Model）的指令與資訊。模型能做的事很多，但它無法讀心，問題越清楚，答案通常越接近你要的結果。

  • 理解 Prompt 的基本組成。
  • 能用五個要素改寫模糊的提問。
  • 知道如何根據回答逐步調整。

Prompt 的五個要素

要素說明範例
角色希望模型以什麼身分回答你是一位資深的國中數學老師
任務要完成的事，動詞要具體幫我設計三題一元一次方程式練習
背景對象、目的、已知資訊學生剛學完移項，容易算錯正負號
格式輸出的結構與長度用表格呈現，附簡短解答
限制不要做什麼、字數、語氣不要使用分數，用語淺白

不一定每次都需要五項齊全。任務與背景通常最重要，其餘依需求加入。

實作：把模糊提問改寫清楚

步驟 1：寫下原本的問法

幫我寫一份學習計畫

預期結果：模型會給出很通用的計畫，因為它不知道你的程度與時間。

步驟 2：補上背景與目標

我是完全沒有程式經驗的上班族，每週可學習 5 小時，
希望 8 週後能用 Python 整理 Excel 資料。

步驟 3：指定格式與限制

請以表格列出每週的主題、練習內容與預估時間。
每週練習不超過 3 項，用語避免艱深術語。

步驟 4：檢視回答並追問

若第 3 週太難，可直接回覆「請把第 3 週拆成兩週，並加入一個簡單範例」。多輪調整往往比一次寫出完美 Prompt 更有效率。預期結果：內容逐步貼近你的程度。

注意事項與常見問題

模型回答錯了怎麼辦？

模型可能產生看似合理但不正確的內容。涉及事實、數字、法規或醫療時，請對照可靠來源查證。

可以把個人資料放進 Prompt 嗎？

請避免輸入密碼、金鑰、身分證字號或他人隱私資料。實際的資料處理方式請參考所使用服務的官方說明。

Prompt 越長越好嗎？

不一定。重點是資訊相關且清楚，重複或互相矛盾的敘述反而會讓結果不穩定。

重點整理

  • 用角色、任務、背景、格式、限制檢查你的提問。
  • 先寫出可用的版本，再依回答逐步調整。
  • 重要內容務必自行查證，並保護個人資料。
